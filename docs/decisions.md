# Решения и допущения

## Принятые решения

1. Используем Docker Compose, а не установку CUPS/Avahi непосредственно в Ubuntu: конфигурация переносима, а обновление и резервное копирование проще воспроизводить.
2. Используем отдельные контейнеры CUPS и Avahi: у сервисов разные обязанности и независимые журналы/циклы обновления.
3. Используем host network: это наиболее надёжный режим для AirPrint/mDNS в одной домашней сети.
4. Адрес и URI принтера задаются через `.env`, чтобы смена принтера или IP не требовала пересборки образа.
5. Первой поддерживаемой очередью будет одна Epson L3250; расширение до нескольких принтеров отложено до подтверждения базового сценария.

## Требующие подтверждения на этапе 0

- фактический IPP URI L3250: первоначальная гипотеза — `ipp://192.168.1.207/ipp/print`, но его необходимо проверить с сервера;
- модель сетевого интерфейса Ubuntu и подсеть, которую следует разрешить в CUPS;
- наличие на хосте уже работающих CUPS, Avahi или других процессов, использующих порт 631 либо UDP/5353;
- наличие DHCP-резервации для `192.168.1.207`.

## Критерии успешного проекта

1. iPhone в той же LAN сам показывает «Epson L3250 — Дом» в стандартном меню печати.
2. PDF и фотография печатаются без Epson iPrint.
3. После перезапуска Docker и Ubuntu функция сохраняется.
4. Изменение IP принтера требует только правки `.env` и штатной команды применения конфигурации.
